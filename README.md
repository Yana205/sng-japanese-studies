# SNG Japanese studies – April 2027

Single-page guide to Japanese-language study at Shinjuku Japanese Language Institute (April 2027 intake): deadlines, fees, housing, visa and documents.

Static site (React via vendored UMD builds, no build step). Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

Run locally: `python3 -m http.server` and open http://localhost:8000.
